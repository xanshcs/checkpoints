## **1b. Thin-and-light laptop**

### **1. Could it run both guests simultaneously?**

| Part           | Laptop specification         | Assessment                                                         |
| -------------- | ---------------------------- | ------------------------------------------------------------------ |
| CPU            | 2 cores / 4 threads, 1.1 GHz | Limited processing power for two VMs.                              |
| Virtualization | AMD-V supported and enabled  | Hardware virtualization is available.                              |
| Memory         | 8 GB LPDDR4X, soldered       | Limited memory for two guests and Windows.                         |
| Storage        | 128 GB eMMC, 31 GB free      | Limited space for virtual disks.                                   |
| OS             | Windows 11 Home in S mode    | S mode restricts traditional virtualization software installation. |

**Resource calculations**

| Resource | Calculation                                 | Result                                                               |
| -------- | ------------------------------------------- | -------------------------------------------------------------------- |
| CPU      | Guest 1 vCPUs + Guest 2 vCPUs               | Must fit within 4 logical processors, leaving capacity for the host. |
| RAM      | Guest 1 RAM + Guest 2 RAM + 2–3 GB host RAM | Must not exceed 8 GB.                                                |
| Disk     | Guest 1 disk + Guest 2 disk                 | Must fit within 31 GB free space, with additional room for the host. |

**Assumption:** Windows requires approximately 2–3 GB RAM for basic operation. Actual VM sizes must be taken from the Labs 1–2 build log.

**Conclusion:** The laptop is unlikely to run both guests comfortably at the same time. Exact confirmation requires the two VM configurations.

### **2. Upgrade first**

| Part             | Can it be upgraded?    | Reason                                                     |
| ---------------- | ---------------------- | ---------------------------------------------------------- |
| CPU              | No, normally soldered  | Cannot practically replace the processor.                  |
| RAM              | No                     | LPDDR4X memory is soldered to the motherboard.             |
| Storage          | No, eMMC is soldered   | Cannot replace it with a conventional SSD internally.      |
| Operating system | S mode can be disabled | Allows installation of compatible virtualization software. |

**Recommendation:** I would use a more powerful computer with at least 16 GB RAM and an SSD. If that is not possible, I would run one virtual machine at a time or use a remote computer.
