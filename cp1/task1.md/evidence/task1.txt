## 1b. Thin-and-light laptop

### 1. Could it run both guests simultaneously?

| Part | Specification | Assessment |
|---|---|---|
| CPU | 2 cores / 4 threads, 1.1 GHz | Limited processing power |
| Virtualization | AMD-V supported and enabled | Supported |
| Memory | 8 GB LPDDR4X, soldered | Limited for two VMs |
| Storage | 128 GB eMMC, 31 GB free | Limited disk space |
| OS | Windows 11 Home in S mode | Restricts traditional virtualization software |

### Resource calculations

| Resource | Calculation | Requirement |
|---|---|---|
| CPU | Guest 1 vCPUs + Guest 2 vCPUs | Must leave CPU capacity for Windows |
| RAM | Guest 1 RAM + Guest 2 RAM + 2–3 GB for host | Maximum 8 GB |
| Disk | Guest 1 disk + Guest 2 disk | Maximum 31 GB available |

Assumption: Windows needs approximately 2–3 GB RAM for basic operation.

Conclusion: Running both guests simultaneously is unlikely to be comfortable. Exact confirmation requires the VM sizes from the Labs 1–2 build log.

### 2. Upgrade first

| Part | Upgrade possible? | Reason |
|---|---|---|
| CPU | No | Normally soldered |
| RAM | No | Soldered LPDDR4X |
| Storage | No | Soldered eMMC |
| Operating system | Yes, S mode can be disabled | Allows more software installation options |

Recommendation: Use a computer with at least 16 GB RAM and an SSD. Alternatively, run one VM at a time or use a remote computer.

1b. A machine you have never seen: thin-and-light laptop
1. Could it run both guests simultaneously?
Laptop specifications:
•	CPU: 2 cores / 4 threads.
•	RAM: 8 GB.
•	Storage: 128 GB eMMC, with 31 GB free.
•	OS: Windows 11 Home in S mode.
To decide whether both VMs can run, compare their combined requirements against the laptop's resources.
Resource	Available	Calculation
CPU	2 cores / 4 threads	Add the vCPUs allocated to both guests.
RAM	8 GB	Guest 1 RAM + Guest 2 RAM + host RAM.
Disk	31 GB free	Guest 1 disk + Guest 2 disk + host free-space reserve.
Assumptions: Reserve approximately 2–3 GB RAM for Windows and background processes. Avoid allocating all CPU threads to virtual machines.
Windows 11 Home in S mode is also a limitation because it restricts installing conventional desktop virtualization software.

The biggest limitation is memory.
•	RAM: 8 GB is limited for running two VMs. It is soldered and cannot be upgraded.
•	Storage: eMMC is soldered and cannot be replaced like a normal SSD.
•	CPU: The processor is generally soldered and not upgradeable.
•	Operating system: Switching out of S mode would make installing conventional virtualization software easier.
My recommendation: If both guests require substantial resources, use a more powerful laptop or desktop with at least 16 GB RAM and an upgradeable SSD. Otherwise, run one VM at a time or use a remote computer for virtualization.
